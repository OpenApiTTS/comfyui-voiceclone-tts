# 登记与发布

目标：用户能在 ComfyUI-Manager 里搜到「VoiceClone TTS」直接安装。两条路，建议 A 为主、B 为兜底，可同时做。

---

## A. Comfy Registry（推荐）

Manager 现在主推这条，带语义化版本、安全扫描和 verified 标记。

**需要人工做的三步：**

1. 到 <https://registry.comfy.org> 注册 publisher。个人主页 `@` 后面那串就是 publisher id，**全局唯一且不可更改**（会进节点 URL）。
2. 到 <https://registry.comfy.org/nodes> 选中 publisher，创建 API Key，妥善保存（丢了只能重建）。
3. 把 `pyproject.toml` 里 `[tool.comfy] PublisherId` 的 `openapitts` 换成第 1 步拿到的真实 id。

**然后二选一发布：**

```bash
# 方式一：本地命令行
pip install comfy-cli
comfy node publish        # 按提示粘贴 API Key
```

```
方式二：GitHub Actions（已配好 .github/workflows/publish_action.yml）
仓库 Settings → Secrets and variables → Actions → New repository secret
  Name:   REGISTRY_ACCESS_TOKEN
  Secret: 第 2 步的 API Key
之后改 pyproject.toml 的 version 推 main 即自动发布
```

**注意事项：**

- `[project] name` 是 `comfyui-voiceclone-tts`，**发布后不可更改**，并且会成为用户机器上 `custom_nodes/` 下的子目录名——必须和仓库名保持一致，README 的安装路径说明才不会对不上。
- 版本一经发布不可覆盖，改了要发新版本号。
- `.comfyignore` 已排除 `docs/`、`.github/`，发布包里不会带这些。
- `Icon` 字段当前是注释状态。有图标（SVG/PNG/JPG/GIF，≤800×400）后解开并填 URL。

```
Adds VoiceClone TTS — voice cloning and TTS nodes.

Repo: https://github.com/OpenApiTTS/comfyui-voiceclone-tts

Four nodes under the `audio/VoiceClone` category: Upload Voice, Voice List,
TTS, and One-Click. Outputs both a file path and native ComfyUI `AUDIO`.

  same voice, and concatenated with the stdlib `wave` module.
- Tested on macOS and Windows.

Two example workflows are included under `workflows/`.
```
